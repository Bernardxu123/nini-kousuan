# 天天口算 · 知识图谱智能出题系统 (Kousuan Lab)

> 为上海嘉定华五小学（徐行镇）一年级学生「妮妮」量身定制的数学口算练习与思维培养系统。  
> 结合国家课程标准与知识图谱，融合认知科学文献，告别机械刷题，实现精准分层与科学导学。

---

## 🌟 核心特色与更新

1. **知识图谱严格遵循沪教版教材顺序**：
   - 知识点底层基于 [cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy)，重新构建层级权重，严格按照课本顺序排列：**一年级上册 → 一年级下册 → 二年级上册 → 二年级下册……**
   - 界面支持一键分段筛选（一年级上 / 一年级下 / 二年级 / 全部），一目了然。

2. **规范书写，彻底抛弃方块框 `□`**：
   - 传统方块框空间逼仄，阻碍铅笔书写体验。
   - **直算题**：保留清晰的标准等号 `＝`，后接 52px 宽的下划书写线 `____`，书写顺手；
   - **逆向填空与等式平衡题**：采用小学标准大圆括号 `（　　）`；
   - **应用题解答区**：提供规范的「【算式】_____________」、「【答】_____________」答题线。

3. **连加连减与项数自由控制**：
   - 支持 **2 项式**（如 `3 ＋ 5 ＝`）、**3 项式**（如 `3 ＋ 4 ＋ 2 ＝`、`9 － 3 － 2 ＝`）、**4 项式**（如 `2 ＋ 3 ＋ 1 ＋ 2 ＝`）灵活勾选控制；
   - 支持细分题型筛选（仅连加、仅连减、加减混合），精准匹配孩子当周在校学习节奏。

4. **妮妮专属画像与错题靶向自适应引擎**：
   - 记录错题与错因归因（看错符号、抄错数、没读懂题、计算失误等）；
   - 每日组卷自动扫描妮妮历史未攻克错题，生成同数族与逆运算的变式强化题（卷面带黄色强化标记）；
   - 支持「一键生成妮妮错题攻坚卷」，精准靶向消灭薄弱点。

5. **儿童阅读理解与审题认知科学脚手架**：
   - **文字全拼音标注**：应用题关键生字与全句逐字拼音对齐；
   - **内置语音朗读伴读**：Web Speech API 0.82x 慢速童声朗读，口语化朗读算式与题目，解决 6 岁儿童字词解码瓶颈（Decoding Bottleneck）；
   - **新加坡数学 CPA 与十格阵（Ten-frame）**：配备直观具象图形，让孩子动手涂色感知数量；
   - **上海小学「讲讲算算」三步法落地**：①圈数字与单位；②看图说故事（部分与整体、变多变少）；③列式计算；
   - **每日 1 分钟常频词卡（Sight Words）**：专项突破「一共、还剩、原来、又买来」等高频审题词。

6. **严格遵守近视防控国标（GB 40070-2021）**：
   - 一二年级字号严格 ≥16pt、行距 ≥5mm、行高 ≥8mm；
   - 单页排版 4 列 × 12 行 ＝ 48 题标准版面，绝不压迫字号，无视觉噪音装饰。

7. **Cloudflare Pages + KV 云端部署与多端同步**：
   - 提供完整的 Cloudflare Functions 无服务器端点；
   - 支持 PC 电脑打印、手机/iPad 随时随地在线批改、错题实时云端同步；
   - **写入采用「服务端合并」策略**：`POST /api/sync` 会先读取云端旧数据，再按「历史并集去重、错题计数合并、掌握度取大、配置/台账/试卷防覆盖」合并后写回，因此电脑端与手机端交替使用不会互相覆盖数据；
   - 手机端进入页面及切换「学情足迹 / 错题本」时会自动从云端拉取最新数据，提交批改后显示同步结果与上次同步时间。

## ☁️ Cloudflare Pages + KV 部署保姆级教程

> **好操作吗？**  
> **答案：非常简单，零成本、免服务器维护，5 分钟即可搞定！**  
> Cloudflare 免费计划每日提供 100,000 次免费读写，全球 CDN 加速，手机和电脑无缝同步。

### 部署 4 步走：

1. **上传代码到 GitHub 仓库**
   ```bash
   git init
   git add .
   git commit -m "feat: 妮妮口算实验室系统"
   git remote add origin https://github.com/<你的用户名>/kousuan-lab.git
   git push -u origin main
   ```

2. **在 Cloudflare Dashboard 创建 Pages 项目**
   - 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)；
   - 点击左侧导航栏 **Workers & Pages** → **Create Application** → 选择 **Pages** → **Connect to Git**；
   - 授权并选择你的 `kousuan-lab` 仓库，点击 **Begin setup**；
   - 构建设置（Build Settings）：
     - **Framework preset**: `None`
     - **Build command**: 留空（不填）
     - **Build output directory**: `.`（填写一个点，即根目录）
   - 点击 **Save and Deploy**。

3. **创建 KV 数据库并绑定**
   - 在 Cloudflare 控制台左侧点击 **Storage & Databases** → **KV**；
   - 点击 **Create a namespace**，名称填写 `KOUSUAN_KV`，点击 **Add**；
   - 返回刚才部署的 Pages 项目页面，进入 **Settings** 标签页 → **Functions**；
   - 向下滚动找到 **KV namespace bindings**，点击 **Add binding**：
     - **Variable name（变量名）**：必须填写 `KOUSUAN_KV`（全部大写）
     - **KV namespace（绑定的数据库）**：选择刚才创建的 `KOUSUAN_KV`
   - 点击 **Save**（保存）并重新部署一次项目。

4. **部署完成与体验**
   - 打开 Cloudflare 提供的线上链接（例如 `https://kousuan-lab-xxx.pages.dev`）；
   - 页面右上角将自动显示 **「☁️ 云端同步开启」** 绿色徽章；
   - 无论在家里电脑打印，还是外出用手机批改，妮妮的学习档案和错题记录都会实时同步！

## 🖨️ A4 打印与练习建议

1. **打印设置**：
   - 快捷键 `Ctrl + P`（Mac 为 `Cmd + P`）；
   - 目标：选择「另存为 PDF」或直接连接打印机；
   - 纸张：**A4**，缩放：**100%**，边距：**默认**（代码已通过 `@page` 定制 13mm/14mm 边距）；
   - **务必勾选「背景图形」**（确保十格阵底色与词卡背景正常打印）。
2. **结构分配**：
   - **第 1 页**：纯算式＋思维变式（48 题天天练，约 6–8 分钟完成）；
   - **第 2 页**：图文应用题（带十格阵与「讲讲算算」引导）；
   - **第 3 页**：高频词卡（可裁剪成字卡，每天指读 1 分钟）。
