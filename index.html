🛠️ Cloudflare Pages + KV 极简部署指南（好操作吗？非常简单，3 分钟即可完成）

本项目已内置 Cloudflare Pages Functions 接口（functions/api/sync.js）和 wrangler.toml 配置文件，零代码改动即可部署。

第 1 步：将代码推送到你的 GitHub 仓库

在当前项目文件夹运行以下命令（若已上传则直接看下一步）：

git init && git add . && git commit -m "feat: 妮妮口算天天练" && git push

第 2 步：在 Cloudflare 创建 Pages 项目

  1. 打开 Cloudflare 控制台，左侧菜单点击 Workers & Pages。
  2. 点击 Create Application -> 选择 Pages 选项卡 -> 点击 Connect to Git。
  3. 授权并选中你的 GitHub 仓库，点击 Begin setup。
  4. 构建设置：Framework preset 选 None，Build command 留空，Build output directory 留空或填 .。
  5. 点击 Save and Deploy，几十秒后你的专属域名就生成了（如 https://nini-kousuan.pages.dev）！

第 3 步：创建并绑定 KV 数据库（记录妮妮数据）

  1. 在 Cloudflare 左侧导航栏点击 Storage & Databases -> KV。
  2. 点击 Create Namespace，输入名称 KOUSUAN_KV，点击 Add。
  3. 回到刚创建的 Pages 项目页面，点击顶部的 Settings -> Functions。
  4. 在页面下方找到 KV namespace bindings，点击 Add binding。
  5. Variable name 填写：KOUSUAN_KV，KV namespace 选择刚刚创建的 KOUSUAN_KV。
  6. 点击 Save，重新部署一次。就搞定了！

第 4 步：体验多端自动同步

部署完成后，无论是电脑还是 iPad、手机打开你的专属网址，系统都会自动识别到云端数据库（状态变为绿色 🟢 已连接），妮妮每次做题、错题本、打卡历史都会自动实时云端备份，换设备不丢失！
